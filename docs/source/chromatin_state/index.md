# Chromatin State Analysis

EpiNemaPipe performs chromatin-state segmentation and analysis using epigenomic data from *Strongyloides ratti*.

The pipeline uses unsupervised machine-learning, a multivariate Hidden Markov Model to identify chromatin states from binarized epigenomic data.
